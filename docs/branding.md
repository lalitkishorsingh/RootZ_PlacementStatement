# NFSU Portal Branding Sources

The portal uses the original National Forensic Sciences University header logo downloaded from its official website on 13 October 2026. Assets are served locally, without third-party requests or a wider content security policy.

| Asset or colour | Official source |
| --- | --- |
| Header logo, preserved without recolouring | https://nfsu.ac.in/assets/img/NFSU_logo.png |
| Full emblem reference | https://nfsu.ac.in/assets/img/emblem.png |
| Navy `#002147` and gold `#DDB55E` | https://nfsu.ac.in/assets/css/bundle.css |
| University emblem page | https://nfsu.ac.in/emblem |

Navy and gold are used for navigation, primary actions and highlights. Gold buttons use navy text for readability. Success and error states retain distinct semantic colours. The logo's aspect ratio is preserved on desktop and mobile, and it appears on the dashboard/navigation, sign-in, account verification and authenticator pages.

These are website-derived colours, not a claim that the university supplied or approved a formal brand manual. The application remains a student project for institutional evaluation, as described in the README.
